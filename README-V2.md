# 森间 · 四季庭院

此目录为独立的 V2 源码副本。原版 four-seasons 及原压缩包均保留，界面不显示版本号。

## 本轮调整（2026-09-15）
- 两棵古树扩大树冠、增粗树干与根系；春季繁花，夏秋浓密叶冠，冬季落叶。
- 连续侧墙和整体山墙封到屋顶；正面为两侧叠放的方格推拉门，保留敞开的中央入口。
- 移除床与原坐垫，改为茶桌左右两只鼓起的软坐垫。桌面放茶盘、空腔茶杯、围棋盘和线装书。
- 书架有高低、倾斜、横放的书籍和陶器摆件；柜面有小相框、杯子与陶罐；挂画为代码绘制的简约山水。
- 成片草地使用实例绘制，根部固定并随低频风场起伏。移动设备降低草叶数量和像素比。
- 河岸石头改为不规则风化轮廓，去除绿色盖片。移除侧面盆栽与右侧长凳，仅保留两只加高加大的前方花盆。
- 四季诗句按请求替换，删除原底部文案、右上天气提示和界面版本号。
- 天气只提供晴与雨／雪，默认晴天，无自动天气变化。季节和昼夜仍可自动推进或手动控制。
- 手机竖屏扩大可缩放范围与初始取景，远近取景补偿雾化强度。

保留溪流波纹、雨滴涟漪、冬季结冰、小猫、蝴蝶、萤火虫及四季陈列物。全部模型和纹理由代码生成，无外部素材。

## 本地运行
Node.js 22.13+；执行 `npm ci`，再执行 `npm run dev`。
预览地址：http://localhost:5174/ 。原版使用 5173。

检查：`npm run typecheck`、`npm run build`。
本机 npm 包装器路径异常时，可使用：
`node node_modules/typescript/bin/tsc --noEmit`
`node "C:/Program Files/nodejs/node_modules/npm/bin/npm-cli.js" run build`

## 源文件
- app/garden-v2.ts：程序化场景、天气、季节与时间。
- app/forms-v2.ts：枝干、叶片、软垫、石头、完整山墙及山水画。
- app/page-v2.tsx：交互与诗句。
- app/globals-v2.css：透明轻量界面。

鼠标/单指旋转，右键或双指平移，滚轮/双指缩放。空格暂停时间，H 隐藏界面，R 复位。声音默认关闭。

## 环境融合与点击互动（本轮）
- 小屋与景物共享轻量空气透视；木台、柱脚长出短草，门前有较浅的踩踏草斑。溪岸和小路的草逐渐稀疏、偏湿绿；河石部分埋入地形与草丛。
- 木台下、柱脚和树根补充多层柔和接触阴影；已移除兔子。
- 轻点小猫：合成短猫叫、耳朵回应、尾巴轻动；无需先开启环境声音。
- 轻点溪流：以触点为中心扩散涟漪。冬季冰面为淡淡的环形微光。
- 轻点室内灯或两盏石灯：各自独立切换；手动状态保持到刷新页面。
- 轻点草、花或树：局部衰减摇晃；春季点树额外散落一阵花瓣。
- 拖动、长按、右键与多指缩放不触发点击。涟漪最多 8 组，花瓣池为桌面 120 / 移动设备 72 片；响应不依赖时间播放状态。
- 新文件 app/interactions-v2.ts 包含手势判定和合成猫叫。运行 node --test tests/interactions-v2.test.mjs 可验证误触防护。

## 木廊与陈设更新
- 溪流外移，前方两座石灯对称；室内同材质地板延伸为木廊，接两级等宽、下方实体的台阶。移除中央门柱和绿色地毯。
- 四片格栅门成对滑动，点击实际门扇开合；透明日式风铃悬在门外，点击增强摇摆并逐渐平息。
- 棋盘置中，两侧坐席各自右手边放棋碗；茶杯与茶壶分置另两边，茶杯上方有少量热气，移除桌上书籍。
- 锦鲤具有斑纹、眼睛、鱼鳍和摆动尾部。花盆单独响应点击，秋季疏花，冬季显露分叉木质枝条。
- 草地为有限椭圆地形，移除远山、远树及天空装饰。柔和草木阵风替代大幅摇晃；冬季树冠有厚雪，点击可抖落雪块。
- 移除互动文字提示。门扇、盆栽采用实际模型拾取；可合并的静态细节与花叶采用合并或实例绘制。
- 新增 app/layout-v2.ts、app/details-v2.ts；运行 `node --test tests/*.test.mjs` 检查地形边界、门前净空、门扇拾取、盆栽互不干扰、落雪回收及手势防误触。
